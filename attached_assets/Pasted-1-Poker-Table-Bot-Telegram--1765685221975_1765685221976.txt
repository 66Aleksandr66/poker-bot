1. Общая информация

Название проекта: Poker Table Bot
Платформа: Telegram
Тип бота: Частный/групповой бот для учета кэш-игр в покер
Цель:
Автоматизированный учет бай-инов, ребаев, кэшаута и статистики игроков за покерным столом с последующим анализом результатов и развлекательной обратной связью.

2. Роли пользователей
2.1 Обычный игрок

Регистрируется в системе

Участвует в играх

Вводит данные по бай-ину, ребаю и фишкам

Получает персональную статистику и комментарии

2.2 Администратор (1 человек)

Управляет системными настройками

Может редактировать данные игр

Может добавлять/удалять игроков

Имеет доступ ко всей статистике

3. Функциональные требования
3.1 Регистрация пользователей

При первом взаимодействии бот:

Запрашивает имя игрока

Сохраняет Telegram ID + имя

Проверка на повторную регистрацию

3.2 Создание и ведение игры

Админ запускает новую игру командой (например: /start_game)

Каждой игре присваивается:

Уникальный ID

Дата и время начала

3.3 Учет бай-инов и ребаев

Для каждого игрока бот фиксирует:

Buy-in (первоначальный взнос)

Rebuy (каждый дополнительный вход)

Способ внесения денег:

Cash

Zelle

Данные сохраняются с привязкой:

к конкретной игре

к конкретному игроку

3.4 Завершение игры игроком (Cash Out)

Когда игрок выходит из игры, бот:

Запрашивает количество фишек по номиналам

Пример:

$1 × 10

$5 × 6

$25 × 2

Автоматически рассчитывает:

Общую сумму фишек

Итог:

прибыль игрока

убыток игрока

сумму, которую банк должен игроку или наоборот

3.5 Завершение игры всего стола

Админ завершает игру командой (например: /end_game)

Система:

Суммирует все бай-ины

Суммирует все кэшауты

Формирует итоговый отчет:

кто выиграл

кто проиграл

на какую сумму

4. Статистика и аналитика
4.1 Статистика по каждой игре

Для каждой завершенной игры:

Общий банк

Результат каждого игрока (+ / -)

Способ внесения средств

4.2 Общая статистика по игроку

Количество сыгранных игр

Общий выигрыш / проигрыш

Средний результат за игру

Дисперсия результатов

Лучший и худший результат

4.3 Анализ стиля игры

На основании статистики бот:

Определяет стиль игрока по покерной классификации, например:

Tight Passive

Tight Aggressive

Loose Passive

Loose Aggressive

Выдает краткий текстовый обзор стиля игры

5. Шуточные комментарии
5.1 Общие требования

После завершения игры игроку выводится шуточный комментарий

Комментарий зависит от результата:

крупный плюс

небольшой плюс

небольшой минус

крупный минус

5.2 Словарь

Минимум 20 уникальных фраз

Примеры тональности:

ироничная

дружеская

без оскорблений

Фразы выбираются случайно из подходящей категории

6. Административный функционал

Администратор может:

Изменять данные игроков

Корректировать бай-ины / ребаи / кэшауты

Изменять номиналы фишек

Включать / отключать комментарии

Просматривать полную статистику всех игр

7. Технические требования (рекомендуемые)

Язык разработки: Python

Фреймворк: aiogram или аналог

Хранение данных:

SQLite (на старте)

Возможность масштабирования до PostgreSQL

Логирование ошибок

Защита админ-команд по Telegram ID

8. Дополнительные пожелания (опционально)

Экспорт статистики в CSV

График прибыли игрока

Поддержка нескольких столов

Многоязычность (RU / EN)

9. Критерии приемки

Все расчеты выполняются автоматически

Данные не теряются между играми

Админ имеет полный контроль

Интерфейс понятен без инструкций
